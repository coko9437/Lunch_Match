난이도   기능   설명

🔴 고급   좋아요 / 댓글   후기 게시글에 반응 기능 추가

난이도   기능   설명

🔴 고급   실시간 채팅 or 참여 신청   WebSocket or 상태값 저장 필요

난이도   기능   설명

5.맛집정보 카테고리 
난이도   기능   설명
🟢 초급   지도에 내 위치 표시   HTML5 geolocation + Kakao Map API 사용해서 사용자의 현재 위치에 마커 표시
🟢 초급   기본 맛집 리스트 출력   서버에서 전체 맛집 목록을 받아와서 리스트/지도에 렌더링
🟡 중급   가격순 정렬   맛집 데이터의 가격 필드를 기준으로 정렬 (프론트 or 백엔드 정렬)
🟡 중급   음식 종류 필터   '면', '햄버거', '찌개', '탕' 등 카테고리로 분류된 맛집만 필터링해서 보여주기
🟡 중급   평점순 정렬   사용자 평점(리뷰)을 기준으로 내림차순 정렬
🔴 고급   거리순 정렬   사용자의 현재 위치에서 각 맛집까지의 거리 계산 → 가까운 순서대로 정렬 (Haversine 공식 사용)
🔴 고급   지도에서 마커 필터링   음식 종류, 평점, 거리 기준으로 지도 위 마커를 실시간으로 필터링해서 표시
🔴 고급   검색결과와 지도 연동   리스트에서 특정 맛집을 선택하면 지도에서 해당 위치로 이동 및 마커 강조 표시
